# ТВ Пульт (TvRemote)

Пульт для Android TV: стрелки, OK, назад, домой, громкость, запуск YouTube/RuTube/Netflix/Кинопоиск,
клавиатура телефона для ввода текста. Связь идёт по тому же протоколу ADB, которым говорит `adb` с компьютера —
отдельного сервера на ПК не нужно, телефон сам открывает TCP-соединение к телевизору.

## Подготовка телевизора
Включите отладку по сети: Настройки → Device Preferences → About → 7 раз нажать на номер сборки (включает
раздел разработчика), затем Developer options → "Network debugging" / "ADB debugging" (формулировка отличается
между производителями). У части дешёвых ТВ-приставок этого пункта в интерфейсе нет вовсе — тогда придётся один
раз подключить их к компьютеру по USB и выполнить `adb tcpip 5555`, после чего можно пользоваться этим приложением.

## Первое подключение
Введите IP телевизора (порт обычно 5555) и нажмите «Подключиться». Телевизор один раз покажет запрос
«Разрешить отладку с этого компьютера?» — подтвердите его обычным пультом или мышью. После этого телефон
запоминается, и повторных запросов не будет (как и при обычном USB-отладке).

## Устройство протокола
* `core/AdbProtocol.kt` — кадры сообщений (24-байтный заголовок + данные, CRC32), как в `adb`.
* `core/AdbRsaKey.kt` — подпись токена устройства (схема ADB: SHA-1 DigestInfo + токен, PKCS#1 v1.5, сырой RSA)
  и кодирование публичного ключа в формате `mincrypt RSAPublicKey` (с `n0inv` и `R² mod n` для Монтгомери).
* `AdbClient.kt` — TCP-транспорt и разбор диалога CNXN/AUTH/OPEN/OKAY/WRTE/CLSE для одноразовых `shell:`-команд.
* Ядро и сам ADB-клиент покрыты юнит-тестами, включая полный цикл рукопожатия против игрушечного сервера ADB
  в тесте (`gradle testDebugUnitTest`).

## Если кнопка приложения не открывает нужный сервис
Пакеты YouTube (`com.google.android.youtube.tv`) и Netflix (`com.netflix.ninja`) для Android TV подтверждены.
RuTube и Кинопоиск сильно различаются между регионами и прошивками — их имена пакетов в Настройках можно
поправить. Узнать точное имя: установить приложение на ТВ и с компьютера выполнить
`adb shell pm list packages | grep <часть названия>`.
